Build Your Practice: from concept to something agents replay

The concept doc's own test: do players choose "Play again" without being asked? Everything below is ordered to answer that as cheaply as possible.

Phase 0 · built

Playable vertical slice

Every core element, playable end to end.

  • Four agent types that trade savings, skills and natural market
  • Port Prospect as home base: every activity takes a day and costs money
  • Prospecting games: Call-a-thon, Chamber of Commerce mixer, Farmers Market tent, plus warm calls, lunch & learns and referrals
  • A pipeline that goes cold, a book of clients who need service, and rivals who poach
  • Build the practice: workspace, a partner, recruits you train, and systems earned on the trail
  • Journeys on your parchment map: days of hiking, forks, encounters, mentors, cut scenes
  • Hidden risk debt, clawbacks and referrals that ripple into later journeys
  • 8 mini-games and 50+ events
Phase 1 · 2–3 weeks

Playtest with agents

Put the link in front of 5–8 agents, mixing new and experienced. Watch two of them play live. Ask the seven questions from the concept doc right after a run, while it is fresh.

  • Track the one number that matters: how many start a second run unprompted
  • Collect real situations to replace placeholder ones (questions 3, 4 and 5 feed the event deck directly)
  • Tune numbers in the content files: costs, debt odds, client patience
  • Add a short "send feedback" link after the ending screen (a GitHub issue template works)
Phase 2

Depth and replay

  • The other mini-games: Calendar Tetris, The Handoff, Explain It, The Form, Change of Mind
  • A client generator: combine goals, patience, preferences and hidden concerns so no two runs repeat
  • More events per place, especially ones that only fire because of an earlier choice
  • Contact relationships that improve across runs
Phase 3

Presentation

  • Illustrated overworld art and character portraits
  • Sound, small animations, save and resume
  • Only after the loop is proven fun: richer movement and exploration
Phase 4 · optional

Learning-context version

  • A facilitator debrief screen that maps a run to discussion questions
  • Kept separate from, and complementary to, formal policy and compliance training

How it is built

Plain HTML, CSS and JavaScript. No build step, no framework, no server. It runs from GitHub Pages or by opening index.html.

  • js/core.js state, resources, effects, risk debt
  • js/content/ clients, port, world, events: edit these to change the game
  • js/minigames/ one file per mini-game, all with the same interface
  • js/content/career.js savings, payouts, levels, clawbacks
  • js/ui/ map, trail scene, journey loop, game flow, Element Lab

Adding content

  • An event: add an object to js/content/events.js. Pick where it fires, write the text, and give each choice a kind and an effect.
  • A shortcut that bites later: give a choice debt: {tag, sev} and describe the tag in world.js.
  • A client: copy one in clients.js and change the facts, script and destinations.
  • A mini-game: copy a file in js/minigames/; it only has to call done() with an effect.

Hosting on GitHub Pages

  1. Create a repository and push this folder.
  2. Settings → Pages → Deploy from a branch → main, root folder.
  3. Share https://<you>.github.io/<repo>/.
